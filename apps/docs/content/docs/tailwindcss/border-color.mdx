## Usage

You can use a tailwind color class to customize the border color of a squircle.

```tsx
<div className="squircle-border-red-500" />
```

Or you can use a custom color.

```tsx
<div className="squircle-border-[#2dd4bf]" />
```

You can also customize the background color opacity.

```tsx
<div className="squircle-border-red-500/50" />
```

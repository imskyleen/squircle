## Usage

You can customize the width of the border of a squircle by using the `--squircle-border-width` variable.

```css
.squircle {
  --squircle-border-width: 2px;
}
```

The value can be in **px** or a **simple number**:

```css
.squircle {
  --squircle-border-width: 2;
}
```
